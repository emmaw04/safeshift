# safeshift

Exploring how we can handle distribution shift in supervised learning so that our models performance doesn't decline in real life settings.

Test-time adaptation matters because our model needs to be robust to changes in the joint distribution between the input features and predicted labels.

Uses the CIFAR-100 dataset; a popular computer vision benchmark for fine-grained image classification.
